

\# Gerenciador de Fretes



Projeto acadêmico desenvolvido para a disciplina de Introdução à Programação da UNIPAR.



\## Objetivo



Desenvolver um sistema web para organizar cadastros e registros de fretes.



\## Funcionalidades



\- Cadastro e edição de produtos.

\- Cadastro e edição de endereços de origem e destino.

\- Cadastro e edição de transportadores.

\- Registro de fretes com vários produtos.

\- Cálculo do peso total da carga.

\- Verificação da capacidade do veículo.

\- Relatórios de fretes por data.

\- Exportação de relatórios em CSV.

\- Login de administrador.

\- Exclusão de registros restrita ao administrador.



\## Tecnologias utilizadas



\- PHP

\- HTML

\- CSS

\- Bootstrap

\- JavaScript

\- JSON para armazenamento dos cadastros

\- XAMPP para desenvolvimento local
